## Directory Overview

- **Crime/**: Crime data analysis notebooks, Excel analysis, and a Power BI dashboard.
- **Documentation/**: Final project reports and presentation materials.
- **Energy/**: Energy consumption datasets and dashboard files.
- **Final/**: Final consolidated Power BI dashboard.
- **Traffic/**: Smart mobility dataset and traffic dashboards.
- **Traffic/Database/**: Traffic database creation notebook.
- **Waste/**: Waste management dataset and analysis notebook.
